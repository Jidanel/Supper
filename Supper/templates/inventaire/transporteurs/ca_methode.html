1. {% trans "Principe" %}

{% trans "SUPPER ne connaît pas les billets vendus par les agences. Le chiffre d'affaires est donc une ESTIMATION : on déduit, pour chaque véhicule, le voyage qu'il effectue à partir des postes de péage où les agents d'inventaire l'ont vu, puis on le valorise au tarif par passager du maillage des postes." %}

2. {% trans "Un véhicule, une semaine, un voyage" %}

{% trans "Un véhicule est identifié par sa plaque et son agence. Ses passages sont regroupés par semaine (lundi → dimanche). Dans une même semaine, tous les postes où il est vu appartiennent à UN SEUL voyage (aller-retour)." %}

  • {% trans "Vu à un seul poste" %} : {% trans "on suppose que le véhicule a pu rejoindre l'un des postes voisins de celui où il a été vu. On cite ces postes voisins avec leur tarif et on retient le plus éloigné en tarif. Exemple : vu uniquement à Batoufam, il a pu rejoindre Maka (1 500) ou Biamo (3 000) ; on retient Biamo, soit 3 000." %}
  • {% trans "Vu à plusieurs postes" %} : {% trans "on prend le chemin le moins cher entre les deux postes les plus éloignés, en additionnant les tarifs des postes voisins traversés d'après le maillage. Le chemin n'utilise d'abord que les régions des deux postes ; une région supplémentaire n'est ajoutée que si aucun chemin n'existe sans elle." %}
    {% trans "Exemples" %} : Okoa-Maria + Boumnyebel = 1 500 ; Okoa-Maria + Boumnyebel + Sikoum = 1 500 + 2 000 = 3 500 ; Okoa-Maria + New Bonako = Okoa-Maria → Boumnyebel → Sikoum → New Bonako = 1 500 + 2 000 + 3 000 = 6 500 ({% trans "la région Littoral est ajoutée car Centre et Sud-Ouest ne sont pas voisines" %}).

{% trans "Si le véhicule est observé sur plusieurs semaines de la période, on retient la semaine où son trajet est le plus long : chaque observation ne montre qu'une partie de sa ligne, la plus complète est la meilleure approximation." %}

3. {% trans "Calcul du chiffre d'affaires d'une semaine" %}

{% trans "CA semaine" %} = {% trans "tarif du trajet" %} × {% trans "places" %} × 2 ({% trans "aller-retour" %}) × {% trans "nombre de tours par semaine" %}
  • {% trans "Places" %} : {% trans "borne inférieure de la fourchette de la fiche" %} — Coaster {{ p.places_coaster }}, {% trans "grand bus ordinaire" %} {{ p.places_bus_ordinaire }}, {% trans "grand bus climatisé" %} {{ p.places_bus_clim }}, Hiace {{ p.places_hiace }}. {% trans "Le bus est supposé plein (estimation théorique)." %}
  • {% trans "Aller-retour" %} : {% trans "une agence de transport qui quitte un poste pour un autre fait nécessairement le retour : le tarif est donc compté deux fois." %}
  • {% trans "Tours par semaine" %} : {% blocktrans with s=p.seuil_regions l=p.tours_longs c=p.tours_courts %}si le trajet traverse plus de {{ s }} régions (ex. axe Extrême-Nord – Nord – Est – Centre – Littoral) : {{ l }} aller-retour par semaine (hypothèse minimale) ; sinon {{ c }} aller-retour par semaine.{% endblocktrans %}
  • {% trans "Bus climatisé" %} : {% trans "on ajoute 2/3 du tarif normal : le CA est multiplié par" %} (1 + {{ p.majoration_clim }}).
{% trans "Exemple" %} : Coaster {% trans "vu à Okoa-Maria et Boumnyebel" %} — 1 500 × {{ p.places_coaster }} × 2 × {{ p.tours_courts }} {% trans "par semaine (trajet de 1 région, donc tours courts)" %}.

4. {% trans "Extrapolation à la période" %}

{% trans "CA période" %} = {% trans "CA semaine" %} × ({% trans "nombre de jours de la période" %} ÷ 7)

{% trans "Mensuel : jours du mois ÷ 7 (ex. 31 jours = 4,43 semaines). Semestriel : 181 ou 184 jours. Annuel : 365 ou 366 jours. Le véhicule est supposé tenir le même rythme pendant toute la période." %}

5. {% trans "Limites à connaître" %}

  • {% trans "C'est une estimation à pleine capacité, pas un encaissement réel." %}
  • {% trans "Un véhicule vu une seule fois dans la période est quand même extrapolé à toute la période." %}
  • {% trans "Une plaque mal saisie compte comme un véhicule de plus : utilisez le rapprochement des plaques avant de calculer." %}
  • {% trans "Les passages à un poste non relié au maillage sont ignorés." %}
  • {% trans "Le tarif d'une liaison provient du document « Maillage des postes voisins » ; en cas de tarifs différents, le plus faible a été retenu." %}
